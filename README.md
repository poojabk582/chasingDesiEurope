# Website

A website project built from the FWAI starter template.

## Project Structure

- `index.html` - Main website entry point
- `digest/` - Content and digest features
- `images/` - Static assets and images
- `scripts/` - Utility scripts
- `chasemate-board/` - Chatbot and Supabase integration

## Documentation

- `PRD.md` - Product Requirements Document
- `TECH-STACK.md` - Technology stack and architecture
- `IMPLEMENTATION-PLAN.md` - Implementation plan and steps
- `AGENTS.md` - AI agent operating instructions

## Getting Started

1. Install dependencies: `npm install`
2. Open `index.html` in a browser, or serve with any static server
